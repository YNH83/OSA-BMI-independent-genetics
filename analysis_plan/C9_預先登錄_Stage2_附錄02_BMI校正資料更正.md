# C9 Stage 2 附錄 02：兩項資料來源其實已校正 BMI（皆於看到結果後才發現）

**原因** Stage 2 登錄時只核對了 GWAS Catalog 的性狀名稱與樣本數，沒有先讀原文方法確認是否以 BMI 為共變項。
在本題 (把 OSA 拆成經 BMI 與不經 BMI) 中，已校正 BMI 的外部性狀會產生對撞偏誤，不適合拿來比較兩個因子。

## 1. A2 血壓（Evangelou 2018，GCST006624 / GCST006630）
- 原文方法 (PMC6284793)：UKB 分析共變項含 BMI，作者並提醒可能有對撞偏誤。發現時 A2 已執行，結果 FAIL。
- 替代來源查證：Keaton 2024 (GCST90310294，PMID 38689001，PMC11096100) 亦校正 BMI。目前未找到同等規模且未校正 BMI、可直接下載的血壓 GWAS。
- 處置：A2 維持預先登錄判讀 (FAIL)，結果並列此限制；不以事後選擇的資料取代。

## 2. A5 打鼾（Campos 2020）
- 登錄的 GCST009761 原始檔名為 `Campos_prePMID_Snoring-adjustedbyBMI.gz`，即 BMI 校正版；未校正的主分析為 GCST009760 (`Snoring-mainAnalysis`，152,302 例 / 256,015 對照)。
- 發現時 GCST009761 已執行 (cor(F_BMI) −0.006、cor(F_NonBMI) 0.543)。
- 處置：以 GCST009760 重跑，作為登錄性狀「打鼾」的正確資料；GCST009761 結果保留並標註 BMI 校正。兩者並列報告。

## 3. 其餘 A4、A5 來源（在執行前逐篇查證原文方法）
睡眠時長 Dashti 2019 主分析未校正 BMI；晝夜型 Jones 2019 共變項為年齡、性別、中心、批次；
FEV1/FVC Shrine 2019 為年齡、年齡平方、性別、身高、吸菸；認知表現 Lee 2018 為性別、出生年、主成分；
收入 Hill 2019 已執行，讀我檔未列 BMI；FinnGen 端點以年齡、性別、主成分、批次為共變項。

## 4. 往後規則
任何外部性狀 GWAS 進入 C9、C1b 分析前，先讀原文方法確認是否校正 BMI 或其他與本題因子相關的性狀，查證結果寫入資料表。
